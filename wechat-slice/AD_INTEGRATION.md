# 广告接入（未发布）

已预留微信原生横幅广告和激励视频通道，广告位 ID 默认留空，不影响免费试玩。

## 配置

在微信公众平台开通流量主、创建对应广告位后，修改 `miniprogram/config/ads.js`：

```js
module.exports = {
  enabled: true,
  bannerAdUnitId: '你的横幅广告位 ID',
  rewardedVideoAdUnitId: '你的激励视频广告位 ID',
};
```

ID 必须是平台提供的 `adunit-...`，不要填写 AppID。`enabled: false` 关闭全部广告。支持只配置一种广告。

横幅显示在物品榜单下方，切割、全屏和弹窗期间隐藏，加载失败自动隐藏。激励视频由结算页按钮主动打开，完整观看后解锁下一局金色刀光，只改外观；提前关闭、加载失败或无法确认观看完成均不发奖。原有30种物品、无限刀数、1/2/3秒和本机排名继续免费使用。奖励只保留在当前页面，使用一局后消耗。

## 测试与发布状态

本版未上传或发布到微信。广告生命周期使用模拟 API 验证，未接入真实广告位，未验证真机广告展示或收益。用户已反馈此前基础游戏在 iPhone 可玩，这不代表本次广告已通过真机测试。

填入真实 ID 后，用对应正式小程序 AppID 导入，在微信开发者工具与 iPhone 微信中验证：横幅展示、完整观看领取、提前关闭不领取、无广告库存、重复点击、返回后台、页面退出和下一局奖励消耗。完整观看奖励出现前后，排名规则应相同。广告可用性取决于账号权限、微信版本及平台返回的库存。

在项目目录运行 `npm test` 验证游戏和广告接口；导入试玩不需要安装构建依赖。
