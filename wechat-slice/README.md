# 万物切切乐 · 微信小程序

这是可导入微信开发者工具的原生小程序项目，使用 WXML、WXSS、微信 Canvas 与音频接口。所有物品、图片、音效都随包提供，游戏运行不依赖网站或外部资源域名。

## 导入与手机预览

1. 解压项目，打开微信开发者工具，选择「小程序」→「导入项目」。
2. 项目目录选择包含 `project.config.json` 的 `wechat-slice` 文件夹。
3. 填入你的小程序 AppID；代码中的 `touristappid` 是未绑定账号的占位值。仅在工具里查看或调试时，可使用工具提供的「无 AppID / 测试号」选项，具体能力以工具提示为准。
4. 开启 ES6 转 ES5 与增强编译，使用基础库 3.6.4 或更新版本。项目已配置这两项，不需要先安装 npm 依赖，不需要「构建 npm」。
5. 工具编译后，使用「预览」或「真机调试」，在 iPhone 的微信内扫码。真机预览所用账号须具备对应 AppID 的开发或体验权限。

发布需要绑定自己的 AppID，登录微信开发者工具上传，并在微信公众平台提交审核和发布。当前交付的是源码项目，尚未上传、审核或发布，也没有已发布的小程序二维码。

## 已保留的玩法

- 30 种物品，6 个类目；真实大小、外形、材质与音效不同。
- 每轮只切一种物品；手指连续来回滑动，不用反复抬手。
- 刀划到哪片，就把哪片分成两片；沿实际刀痕切割。
- 上抛 0.8 秒，悬停可选 1 / 2 / 3 秒，随后 0.35 秒快速坠落并结算。
- 没有固定刀数或碎片数上限；几何精度与每次输入的计算预算用于保持流畅。
- 原生 WebGL 立体材质与切面；WebGL 不可用时保留 2D 切割玩法。
- 每种物品独立本机榜单，各保留最高 100 条；新成绩显示悬停时长。
- 昵称、音效开关和悬停时长使用微信本地存储。没有跨设备或全球排行榜。
- 支持展开画面、横竖屏适配、后台暂停及返回后的触摸重新定位。

默认音效使用微信 Web Audio；接口不完整时使用随包的 30 种独立切割 WAV 和开局、倒计时、结算 WAV。音效遵循手机静音设置。物品卡片图片使用本地 PNG，避免依赖微信对 SVG 的支持。

## 文件

- `miniprogram/pages/game/`：页面、触摸事件、选择器、结算和榜单。
- `miniprogram/lib/game.js`：真实碎片切割、计时和物理运动。
- `miniprogram/lib/visual3d.js`：立体表面、切面与砧板。
- `miniprogram/lib/platform.js`：原生 Canvas、触摸坐标、动画和生命周期适配。
- `miniprogram/lib/sound.js`：微信原生音频及本地 WAV 降级。
- `miniprogram/lib/scores.js`：成绩校验、排名与本机存储。
- `miniprogram/assets/`：30 张 PNG 与 33 个 WAV。
- `tests/`：可执行逻辑验证与实际结果。
- `TESTING.md`：验证范围与微信真机待测清单。

## 本地验证

安装 Node.js 18 或更新版本后，在项目根目录运行 `npm test`。这项检查不需要 npm 安装或联网。

当前模拟微信接口的 11 组检查通过，其中完整运行了 30 种物品 × 1 / 2 / 3 秒共 90 轮。验证不能替代微信开发者工具编译与真实手机测试；当前环境没有连接真实 iPhone，也没有运行微信开发者工具。

运行时资源已生成。如需重做图标或音效，可安装开发依赖后运行 `npm run assets`，该步骤还需要 Python 3；日常导入与试玩不需要运行它。
